# Hochschule München

`hm-mark.svg` is the unmodified figurative mark retrieved on 2026-11-02 from
https://assets.hm.edu/_icons/figurative-mark.svg, as referenced by the official
https://hm.edu/ website stylesheet https://assets.hm.edu/_css/styles.css.

The application displays it only when the operator institution is presented as
Hochschule München (including the existing exact V5 demonstration alias).
It is served locally; viewing the application makes no requests to HM servers.
Corporate design contact: https://hm.edu/aktuelles/presse/kontakthochschulkommunikation/index.de.html.
